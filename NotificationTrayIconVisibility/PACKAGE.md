# NotificationTrayIconVisibility

Tells a Windows app whether the user can reach its notification area (system tray) icon.

Windows 11 can hide a tray icon, and can also hide the menu of hidden icons. When both are hidden, an app that hides its window to the tray leaves the user no way to get it back. This can be very confusing for users.

See the [GitHub README](https://github.com/JayBazuzi/NotificationTrayIconVisibility) for more.
